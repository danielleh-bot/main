What the kit got wrong

Building against the kit surfaced five problems worth fixing upstream. Four are extraction bugs, one is an environment limit on my side.

  • Mis-read header.is_dark: false contradicts the rest of the kit. The base ground is #1A1A1A and primary text is #FFFFFF — this is unambiguously a dark site. Any downstream logic branching on is_dark would pick light-mode styling and produce white-on-white. header.background_color is also null. Highest-severity issue in the kit.
  • Mis-read article_title_hero came back as 16px / weight 400. That is a thumbnail measurement, not a hero — it is identical to article_title_card but lighter. The extractor most likely sampled a related-articles rail instead of the headline. I rendered the mock's headline from section_headings (36 / 700) instead, which is the only credible display treatment in the kit.
  • Suspect article_body at weight 600 is implausible for running text. 20px / 32px leading is reasonable; semibold body copy is not. I rendered it verbatim so the demo shows what the kit actually claims — that is why the article paragraphs look heavy. Probably a sampled pull-quote or standfirst.
  • Incomplete buttons.primary.padding is 0px 36px — no vertical padding. Rendered literally the CTA collapses to zero height. I added min-height: 44px to make it tappable. The kit needs either a height or a real vertical padding value. Related: backgrounds.section is null and article_lead is the one acknowledged fallback token.
  • My limit Neither typeface is actually rendering. Satoshi and Clash Grotesk are commercial Fontshare faces; the artifact CSP blocks font CDNs and neither is installed here, so the stacks name them first and then fall back to system grotesques. Sizes, weights, leading and letter-spacing are the extracted values, but letterforms are approximate. Judge the proportions, not the type. Likewise, www.goal.com is blocked by this environment's network policy, so all copy and imagery is placeholder — only the headline and URL come from the kit's own metadata.
